## About

**YK Digital Hub** is a full-service digital agency website built to serve:

- **Web Design & Development** — custom, responsive, conversion-focused websites
- **Digital Marketing** — SEO, Local SEO, Google Ads, Social Media Marketing

**Core specialization:** Healthcare providers (dental clinics, medical practices, hospitals)

**Target markets:** USA · UK · Canada · Australia · Germany · Pakistan

Built to be maintainable by non-developers through a full admin dashboard.

## Features

### Frontend
- ✅ **Dynamic Homepage** — hero with rotating backgrounds, featured services, portfolio, testimonials, blog
- ✅ **Service Pages** — full detail pages with features, process, stats, technologies, FAQs
- ✅ **Portfolio Case Studies** — Web Development & Digital Marketing case study templates
- ✅ **Blog** — listing, category pages, detail pages with related posts
- ✅ **About Page** — founder story, timeline, values, expertise
- ✅ **Contact Page** — working form with email + WhatsApp notifications
- ✅ **Country Flags Marquee** — infinite scroll showing markets served
- ✅ **SEO** — dynamic meta tags, Open Graph, JSON-LD schema, canonical URLs
- ✅ **Fully Responsive** — desktop, tablet, mobile
- ✅ **Accessible** — semantic HTML, ARIA, keyboard support, reduced-motion

### Admin Dashboard
- ✅ **Authentication** — secure login, CSRF, session protection
- ✅ **Service Categories** — 2 fixed parents + dynamic child categories
- ✅ **Services CRUD** — full service management with detailed content tabs
- ✅ **Portfolio Categories** — same hierarchy as services
- ✅ **Portfolio Projects** — full case-study management
- ✅ **Blog Posts** — rich text editor, tags, categories, drafts
- ✅ **Blog Categories & Tags** — reusable taxonomy
- ✅ **Testimonials** — with ratings, photos, featured flag
- ✅ **Contact Messages** — read, filter, mark status
- ✅ **Image Uploads** — drag-and-drop with preview and validation

## Tech Stack

| Layer | Technology |
|-------|-----------|
| **Backend** | PHP 8.2+ |
| **Database** | MySQL 8+ (InnoDB, utf8mb4) |
| **Frontend** | HTML5, Tailwind CSS (CDN), Vanilla JavaScript |
| **Server** | Apache with mod_rewrite |
| **Icons** | Font Awesome 6 |
| **Fonts** | Inter, Space Grotesk (Google Fonts) |
| **Email** | PHPMailer + Gmail SMTP |
| **WhatsApp** | CallMeBot API (optional) |
